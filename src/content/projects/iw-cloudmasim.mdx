IW-CloudMASim is my final year project: a real-time web dashboard for a
multi-agent reinforcement learning cloud task scheduler. Agents trained with
MADDPG allocate incoming tasks across a simulated pool of virtual machines, and
the dashboard streams the state of that allocation as it happens.
